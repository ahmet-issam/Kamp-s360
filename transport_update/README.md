# Transport screen

Copy `lib/features/bus_screen.dart` to the Flutter app and run `install_transport.py --apply` from the Flutter project root with this folder outside the project. The installer backs up existing files and connects HomeScreen automatically. Run `dart format` and `flutter analyze` after installation. This environment has no Flutter SDK, so Flutter compilation must be checked in the app project.

The screen provides campus map search and directions, municipal contact information, hospital route instructions, and existing published transport notices from `AppController.busService` / `campus_services`. Refresh uses the existing backend and displays a failure state if fetching fails.

It does not contain a verified Bingöl campus ring timetable, bus departure feed, live positions or fare data. Those require a published operator source. It does not scrape or infer times. The university and municipality timetable searches did not provide usable published schedules during implementation.

Sources checked 25 October 2026:

- Campus identification: https://iso.bingol.edu.tr/hakkimizda/kampus/
- Municipal contact: https://bingol.bel.tr/tr/iletisim
- Hospital route guide (published 10 June 2026): https://bingoleah.saglik.gov.tr/TR-129833/iletisim.html

Hospital instructions describe transfer connections, not a complete stop sequence or live operation. Map results open externally and are generated by Google Maps. Launch failures show a message. No API keys or new dependencies are required because `url_launcher` already exists in this app.
